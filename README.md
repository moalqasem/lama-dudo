# 🎲 لعبة اللودو الملكية أونلاين (Ludo Online)

لعبة لودو تفاعلية كاملة تدعم اللعب الجماعي في الوقت الحقيقي (Real-time Multiplayer) عبر الإنترنت، أو اللعب الفردي ضد روبوتات الذكاء الاصطناعي (AI Bots).

---

## 🌟 مميزات اللعبة

1. **لعب جماعي أونلاين (Online Multiplayer)**:
   - إنشاء غرف خاصة ومشاركة رمز الغرفة مع الأصدقاء.
   - مزامنة فورية لحركات القطع ورميات النرد باستخدام **WebSockets (Socket.IO)**.
   - دعم من 2 إلى 4 لاعبين (الأحمر، الأخضر، الأصفر، الأزرق).
   - إمكانية ملء أي مقاعد فارغة بروبوتات ذكاء اصطناعي.

2. **لعب سريع ضد الكمبيوتر (Bots)**:
   - إمكانية بدء لعبة فورية بضغطة زر واحدة ضد 3 روبوتات ذكية تتمتع باتخاذ قرارات تكتيكية (الهجوم، حماية القطع، إدخال القطع للبيت).

3. **قواعد اللودو الأصلية المعتمدة**:
   - إخراج القطعة من البيت عند الحصول على الرقم **6**.
   - رمية إضافية عند الحصول على 6، أو عند أكل قطعة الخصم، أو عند إدخال قطعة إلى المركز.
   - قاعدة منع 3 ستات متتالية.
   - مناطق الأمان (النجوم ومربعات البداية) المحمية من الأكل.

4. **تصميم عصري وتجربة مستخدم مميزة**:
   - نرد ثلاثي الأبعاد (3D Cube) متحرك وتفاعلي.
   - رقعة لودو بتصميم عالي الدقة (SVG) متجاوبة مع كافة الشاشات (كمبيوتر، هاتف، تابلت).
   - مؤثرات صوتية مدمجة برمجياً عبر (Web Audio API) دون الحاجة لملفات صوت خارجية.
   - نافذة دردشة مدمجة وإيموجيز تفاعلية بين اللاعبين.

---

## 🚀 طريقة التشغيل

1. **عبر الملف المباشر**:
   - قم بالضغط المزدوج على ملف `start_game.bat`.

2. **أو عبر سطر الأوامر (Terminal)**:
   ```bash
   npm start
   ```

3. **فتح اللعبة**:
   - افتح المتصفح على: [http://localhost:3000](http://localhost:3000)
   - للعب مع الأصدقاء على نفس شبكة الواي فاي المنزلية، شارك معهم عنوان IP الخاص بجهازك، مثل: `http://192.168.1.X:3000`.
